# MVVMSwiftUI

Небольшое iOS-приложение на SwiftUI для просмотра персонажей вселенной Rick and Morty с использованием открытого [Rick and Morty API](https://rickandmortyapi.com/).

## Возможности

- загрузка списка персонажей с пагинацией;
- экран с подробной информацией о персонаже;
- горизонтальная карусель эпизодов;
- повторная загрузка после сетевой ошибки;
- асинхронная загрузка и кэширование изображений;
- обработка отмены параллельных запросов;
- unit-тесты ViewModel и сервисов.

## Архитектура

Проект построен на MVVM и разделён на несколько слоёв:

- **Views** — интерфейс на SwiftUI;
- **ViewModels** — состояние экранов и пользовательские действия;
- **Services** — получение персонажей и эпизодов;
- **DTO / Domain models** — сетевые и доменные модели;
- **Core** — сетевой клиент, обработка ошибок и загрузка изображений.

Для асинхронных операций используются Swift Concurrency (`async/await`, `actor`, `Task`). Зависимости сервисов передаются через протоколы, что позволяет изолированно тестировать ViewModel.

## Требования

- Xcode 16 или новее;
- iOS 15.0 или новее;
- Swift 6.

## Запуск

1. Клонируйте репозиторий.
2. Откройте `MVVMSwiftUI.xcodeproj` в Xcode.
3. Выберите симулятор iPhone.
4. Запустите схему `MVVMSwiftUI`.

Дополнительная настройка и API-ключи не требуются.

## Тесты

Тесты написаны с помощью Swift Testing и проверяют:

- первоначальную загрузку персонажей;
- пагинацию и повторные запросы;
- загрузку эпизодов;
- обработку ошибок;
- преобразование ответов сетевых сервисов.

Для запуска тестов используйте **Product → Test** (`⌘U`).
